# AYXX Office

React + TypeScript + Vite 기반의 설치형 데스크톱 앱 프로젝트입니다.

## 실행 방법

```bash
npm install
npm run dev:electron
```

## 기본 구조

- src/App.tsx: 메인 화면
- src/main.tsx: 진입점
- src/App.css: 스타일
- electron/main.js: Electron 메인 프로세스
- electron/preload.js: Electron preload 스크립트
